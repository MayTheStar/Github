# 🧠 دليل مبسّط لاستخدام GitHub | Simple Guide to Using GitHub

## ما هو GitHub؟

GitHub هو منصة إلكترونية مجانية تُستخدم لحفظ الملفات، تتبّع التعديلات عليها، ومشاركة المشاريع مع الآخرين. يعتمد GitHub على أداة تُدعى Git، وهي نظام لإدارة الإصدارات (Version Control System) يسمح لك بالرجوع لأي نسخة سابقة من ملفاتك، أو التعاون مع فريق في نفس المشروع.

---

## لماذا أستخدم GitHub؟

- 🔒 لحفظ نسخ احتياطية من ملفات مشروعك
- 📈 لتتبع تغييراتك بمرور الوقت
- 👥 للتعاون مع الآخرين في نفس المشروع
- 💼 لعرض أعمالك بشكل احترافي على الإنترنت

---

## كيف أبدأ باستخدام GitHub؟ (بدون أكواد)

### 1️⃣ إنشاء حساب

1. ادخل على [https://github.com](https://github.com)
2. اضغط على "Sign Up"
3. أدخل بريدك الإلكتروني وكلمة المرور

---

### 2️⃣ إنشاء مستودع (Repository)

المستودع هو مكان تحفظ فيه ملفات مشروعك.

1. من الصفحة الرئيسية، اضغط على زر **"New repository"**
2. أدخل اسم المشروع (مثلاً: `تحليل_البيانات`)
3. أضف وصفًا بسيطًا (اختياري)
4. فعّل خيار "Initialize this repository with a README"
5. اضغط "Create repository"

---

### 3️⃣ رفع ملفاتك

1. ادخل على المستودع
2. اضغط على **"Add file"** ثم **"Upload files"**
3. اسحب الملفات من جهازك مثل Excel, Word, PDF، أو صور
4. اضغط "Commit changes" لحفظها

---

### 4️⃣ تعديل ملف README

`README.md` هو الملف الذي يظهر أول ما يفتح أحدهم المستودع. استخدمه لشرح مشروعك أو كتابة أي دليل استخدام أو توثيق.

تستطيع تعديل الملف بالضغط على أيقونة ✏️ ثم كتابة ما تريد.

---

## مصطلحات مهمة

| المصطلح        | المعنى                                                                          |
|----------------|----------------------------------------------------------------------------------|
| Repository     | المستودع، وهو مجلد إلكتروني يحتوي على ملفات المشروع                           |
| Commit         | حفظ تعديل قمت به على الملفات                                                    |
| Push / Pull    | إرسال أو جلب التعديلات بين جهازك و GitHub                                       |
| Branch         | نسخة فرعية من المشروع تُستخدم لاختبار التعديلات قبل إضافتها للمشروع الرئيسي   |
| Clone          | نسخ مستودع إلى جهازك المحلي للعمل عليه                                           |

---

## هل أحتاج إلى أكواد لأستخدم GitHub؟

لا! بإمكانك استخدام GitHub بالكامل عبر الموقع فقط:
- رفع ملفات
- تعديل نصوص
- قراءة تاريخ التعديلات

لكن إذا أردتِ استخدامه بشكل احترافي أكثر (خاصة مع VS Code)، بإمكانك تعلم أوامر `git` لاحقًا.
